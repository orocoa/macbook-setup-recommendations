# Dock 图标位置

此目录为「关闭程序坞中的建议与最近使用的 App」示意预留 5 个图标位。当前页面不会使用截图或自行仿制 Apple App 图标；缺少文件时显示对应的 App 名称，保持前后身份可辨认。

将你拥有使用权的正方形 PNG 放入本目录，并使用以下文件名：

- `app-store.png`
- `pages.png`
- `keynote.png`
- `safari.png`
- `settings.png`

建议：512 × 512 px PNG、透明背景或完整图标画布。页面会在统一的最大 52 × 40 px 显示位内等比完整缩放（object-fit: contain），不裁掉图标内容。这是网页示意尺寸，不代表 Apple 原生图标规范。
