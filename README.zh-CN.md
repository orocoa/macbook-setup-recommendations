# MacBook 设置建议

[English](./README.md)

一份包含 15 项访达、系统设置、实用工具与快捷操作建议的中英双语可视化交互指南，面向刚拿到新 MacBook、希望手动调整使用习惯的用户。每项建议都会说明发生什么变化、在哪里找到、如何手动修改，以及如何恢复原来的行为。

## 直接使用

[打开 MacBook 设置建议](https://kai-nex.github.io/macbook-setup-recommendations/)

无需下载或安装，建议直接在 MacBook 的浏览器中打开。

## 包含什么

- 15 项建议：4 项访达、9 项系统设置、1 项独立工具推荐和 1 项内置快捷操作建议。
- 简体中文和英文内容，可在界面中切换。
- 搜索用户可见的设置内容，包括标题、说明、路径和操作步骤。
- 桌面端 Master–Detail 布局：在左侧选择设置，在不离开页面的情况下阅读右侧详情。
- 使用浏览器 Local Storage 保存的逐项清单。
- 修改前后说明、手动路径、操作步骤、恢复方法和来源链接。
- 静态 JSON 内容；不包含账号、数据库、API、云同步或后端。

## 不会做什么

本指南不会检测 macOS 当前状态，也不会修改任何 macOS 设置。所有系统变更都由用户在访达或系统设置中手动完成。

清单只记录一项建议是否已经处理。勾选既可以表示已经修改，也可以表示阅读后有意保留原状态。清单不能证明 macOS 的真实设置状态。

## 通过 HTTP 本地预览

页面使用 `fetch` 加载 JSON 文件，因此应通过本地 HTTP 服务器预览，而不是使用 `file://` 直接打开 `index.html`。

在本目录运行：

```bash
python3 -m http.server 4177 --bind 127.0.0.1
```

然后打开：

<http://127.0.0.1:4177/>

如果 macOS 安全设置允许，也可以双击 `run.command`。

## 来源与编辑边界

每项建议都包含一个或多个来源链接，主要来自 Apple 支持或《Mac 使用手册》。这些来源用于支持 macOS 功能行为、使用条件和设置位置。

部分数值和工作流是本指南的编辑建议，并非 Apple 默认设置。例如，推荐的触控板速度只是本指南提供的起点；触发角拖移文件是对多个系统功能进行人工测试后形成的组合用法。内部编辑记录保存在 JSON 中，但不会呈现为 Apple 官方结论。

Mos 条目属于独立 App 推荐，不是 macOS 设置，也不代表 Apple 推荐。Mos 需要辅助功能权限来处理鼠标输入，因此指南会先解释权限用途，再引导用户决定是否授权。

视觉内容属于说明性原型：部分是原创 HTML/CSS 概念示意，部分现有图片资产的公开再分发许可尚未确认。公开发布或再分发仓库前，请先阅读 [THIRD_PARTY_NOTICES.md](./THIRD_PARTY_NOTICES.md)。

## 数据检查

准备当前版本的 Node.js 运行环境，然后运行：

```bash
npm test
```

对应的底层命令是：

```bash
node tests/validate-data.mjs
```

测试会检查两种语言的数据文件、必填字段、唯一 ID、来源 URL、视觉类型、引用资产，以及中英文内容的结构一致性。测试不能证明每项建议在所有 Mac 或 macOS 版本上都完全正确。

## 已知限制

- 本指南面向近期 macOS，不记录早期版本的设置路径。
- 设置名称、位置和行为可能因 macOS 版本、Mac 型号、连接硬件、系统语言或账户配置而不同。
- 个人推荐不是统一默认值，不一定适合所有工作流。
- 第三方工具可能需要额外权限，拥有独立许可证，并会在 macOS 之外持续更新；安装前应检查当前版本与权限需求。
- Local Storage 只属于当前浏览器，不提供账号同步、备份，也不能确认真实系统状态。
- 当前版本尚未进行广泛用户研究，也没有完整的跨浏览器兼容矩阵。
- Apple、Adobe 或用户提供的参考资产仍受各自权利约束，不包含在 MIT License 中。
- 原创代码与文档采用 MIT License；第三方名称、商标、截图和参考资产不包含在该授权中，详见 `THIRD_PARTY_NOTICES.md`。


## 贡献方向

有价值的贡献包括：近期 macOS 路径修正、更清楚的修改与恢复步骤、可靠的一手来源、中英文术语修正、无障碍视觉说明，以及可复现的用户测试发现。

除非经过验证的产品需求确实需要，否则不要引入框架、后端、账号系统、数据库或 AI 功能。
