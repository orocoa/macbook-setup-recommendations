从常用键盘快捷键开始

用组合按键完成拷贝、粘贴、撤销、切换应用程序和搜索等常用操作，减少在菜单中寻找的次数。

打开这项设置

工具与快捷操作

开始前确认

  • 功能键／地球仪键的单键动作可在「系统设置」>「键盘」中配置为切换输入法、显示表情等。打开表情建议使用 ⌃⌘ + 空格键，或功能键 + E。

设置路径

任意应用程序 › 屏幕左上角菜单栏 › 菜单项右侧的快捷键符号

操作步骤

  1. 先打开一个应用程序，例如访达或 Safari 浏览器。
  2. 查看屏幕左上角的菜单栏；点开「文件」或「编辑」等菜单，观察许多命令右侧显示的快捷键符号。
  3. 先尝试三个最常用组合：按住键盘上的 ⌘ 键，再按 C 拷贝、V 粘贴或 Z 撤销。
  4. 熟悉后再尝试 ⌘ + 制表键切换应用程序，以及 ⌘ + 空格键打开聚焦搜索。
  5. 不需要打开系统设置；从每天会重复的一个操作开始使用即可。

修改前

每次操作都需要移动鼠标或触控板，再从菜单栏中寻找命令。

修改后

常用操作可以直接用组合按键完成；菜单栏也会在许多命令右侧显示对应的快捷键。

键盘快捷键

操作快捷键描述
关闭⌘-W关闭窗口。
拷贝⌘-C拷贝所选内容。
剪切⌘-X剪切所选内容。
删除删除键删除光标前的字符。
查找⌘-F查找文本。
强制退出⌥-⌘-退出键强制退出无响应的应用程序。
向前删除键功能键 + 删除键删除光标后的字符。
隐藏⌘-H隐藏正在使用的应用程序。
新建⌘-N打开新访达窗口，或在其他应用程序中创建新文稿。
新建标签页⌘-T在访达、文稿或 Safari 浏览器中打开新标签页。
粘贴⌘-V粘贴上一个拷贝或剪切项目的副本。
粘贴并匹配样式⌥-⇧-⌘-V粘贴副本，并匹配当前文稿的样式，而不是保留原始样式。
打印⌘-P打印文稿。
快速查看空格键选中一个或多个项目后，在不打开对应应用程序的情况下预览内容。
退出⌘-Q退出应用程序。
右键点按按住 ⌃ 键点按打开快捷键菜单。
保存⌘-S保存文稿。
全屏截屏⇧-⌘-3将整个屏幕截屏。
截取屏幕所选部分⇧-⌘-4将屏幕的一部分截屏。
打开“截屏”选项⇧-⌘-5截屏或录屏。
全选⌘-A选择所有内容。
显示表情和符号⌃⌘ + 空格键 / 功能键 + E打开字符检视器。单按功能键／地球仪键的结果取决于「键盘」设置。
聚焦搜索⌘-空格键搜索 Mac 上的任何内容。
切换应用程序⌘-制表键再次按下 ⌘ + 制表键 移到下一个应用程序；按下 ⇧⌘ + 制表键 移到上一个应用程序。
撤销⌘-Z撤销上次操作。

恢复原设置

  • 无需恢复。若要更改或停用系统快捷键，在屏幕左上角点按苹果菜单 >「系统设置」>「键盘」>「键盘快捷键」。
