显示访达路径栏

在访达窗口底部查看当前位置及其上级文件夹。

打开这项设置

访达

设置路径

访达 › 显示 › 显示路径栏

操作步骤

  1. 打开访达窗口。
  2. 查看屏幕左上角的菜单栏；确认最左侧显示「访达」。
  3. 在左上角菜单栏中选择「显示」>「显示路径栏」。
  4. 查看访达窗口底部，确认已经出现当前位置的层级路径。

修改前

访达窗口底部不显示层级路径。

修改后

访达窗口底部显示当前位置的层级路径。

恢复原设置

  • 在访达的菜单栏中选择「显示」>「隐藏路径栏」。

来源与版本说明

  • 苹果支持｜在 Mac 上获取文件、文件夹和磁盘信息

路径核对版本为 macOS 27.0.1，日期 2026-10-14；其他系统版本的名称与位置可能不同。
