将窗口最小化为应用程序图标

让最小化窗口收进所属应用程序的程序坞图标，避免每个窗口单独占用程序坞位置。

打开这项设置

系统设置

设置路径

系统设置 › 桌面与程序坞 › 将窗口最小化为应用程序图标

操作步骤

  1. 打开「系统设置」。
  2. 选择「桌面与程序坞」。
  3. 在「程序坞」区域开启「将窗口最小化为应用程序图标」。
  4. 最小化同一应用程序的多个窗口，确认它们不再分别出现在程序坞的独立区域。

修改前

每个最小化窗口会在程序坞中单独显示。

修改后

最小化窗口收进所属应用程序的程序坞图标。

恢复原设置

  • 回到「桌面与程序坞」，关闭「将窗口最小化为应用程序图标」。

来源与版本说明

  • 苹果支持｜在 Mac 上更改“桌面与程序坞”设置

路径核对版本为 macOS 27.0.1，日期 2026-10-14；其他系统版本的名称与位置可能不同。
