显示所有文件扩展名

显示完整文件名，包括 .txt、.pdf 和 .mov 等扩展名，便于识别文件类型。

打开这项设置

访达

设置路径

访达 › 设置 › 高级 › 显示所有文件扩展名

操作步骤

  1. 点按「访达」，打开访达窗口。
  2. 查看屏幕左上角菜单栏；确认最左侧显示「访达」。
  3. 在菜单栏中点按「访达」，然后点按「设置」。
  4. 点按「高级」。
  5. 开启「显示所有文件扩展名」。
  6. 回到包含不同格式文件的访达窗口，确认文件名末尾显示 .txt、.pdf、.mov 等扩展名。

修改前

部分文件名不显示扩展名，仅凭名称不容易判断文件类型。

修改后

文件名显示扩展名，可以直接区分常见文件类型。

恢复原设置

  • 打开访达窗口后，在屏幕左上角菜单栏中点按「访达」>「设置」>「高级」，关闭「显示所有文件扩展名」。

来源与版本说明

  • 苹果支持｜显示或隐藏 Mac 上的文件扩展名

路径核对版本为 macOS 27.0.1，日期 2026-10-14；其他系统版本的名称与位置可能不同。
