自动切换到文稿的输入法

让仍保持打开的不同文稿分别保留已选择的输入法。

打开这项设置

系统设置

开始前确认

  • 至少配置两个输入法，并保持两个测试文稿同时打开。

设置路径

系统设置 › 键盘 › 文字输入 › 编辑 › 所有输入法 › 自动切换到文稿的输入法

操作步骤

  1. 打开「系统设置」，然后选择「键盘」。
  2. 在「文字输入」区域点按「编辑」，再选择左侧的「所有输入法」。
  3. 确认至少已添加两个输入法；这个选项只会在有多个输入法时出现。
  4. 开启「自动切换到文稿的输入法」。
  5. 打开两个文稿：为一个选择中文输入法、另一个选择英文输入法；在两个仍打开的文稿之间切换，确认输入法会随文稿恢复。

修改前

切换文稿后继续使用上一个文稿的输入法。

修改后

返回仍打开的文稿时，系统恢复该文稿之前使用的输入法；关闭文稿后不再保留这一临时对应关系。

恢复原设置

  • 回到「键盘」>「文字输入」>「编辑」>「所有输入法」，关闭「自动切换到文稿的输入法」。
