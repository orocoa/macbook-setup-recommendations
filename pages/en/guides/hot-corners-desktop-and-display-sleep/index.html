Set up Hot Corner workflows

Use the bottom-right corner to show the desktop, and require Command with the top-right corner to put the display to sleep. Also limit wallpaper clicks that move windows out of the way.

Open this setting

System Settings

Settings path

System Settings › Desktop & Dock › Desktop & Stage Manager › Click wallpaper to reveal desktop › Only in Stage Manager

System Settings › Desktop & Dock › Hot Corners

Steps

  1. Take a screenshot of the current Show Desktop setting and the actions assigned to the top-right and bottom-right corners.
  2. Open System Settings, then click Desktop & Dock in the sidebar.
  3. In Desktop & Stage Manager, set “Click wallpaper to reveal desktop” to “Only in Stage Manager.” This option may be labeled Show Desktop in other versions.
  4. Scroll down and click Hot Corners.
  5. For the top-right corner, hold Command while viewing that corner’s pop-up menu, then choose “Put Display to Sleep.”
  6. For the bottom-right corner, choose “Desktop.” This replaces any action currently assigned to that corner.
  7. Click Done.
  8. Test the desktop round trip: In the current app, move the pointer to the bottom-right corner to show the desktop. Begin dragging a desktop file and keep holding it, move the pointer to the bottom-right corner again, wait for the original app to return, then drop the file. If you release the file early, it will not continue following the pointer.
  9. Test display sleep: Hold Command and move the pointer to the top-right corner, then confirm that the display goes to sleep.
  10. The password delay after display sleep is controlled by System Settings > Lock Screen. To lock your Mac immediately, press Control-Command-Q.

Before

A wallpaper click may move windows out of the way, and the two corners may have different actions or no deliberate workflow assigned.

After

The bottom-right hot corner shows the desktop. The top-right hot corner puts the display to sleep only while Command is held. Wallpaper clicks move windows only when Stage Manager is active.

Undo the change

  • Return to Desktop & Dock, use your screenshot to restore the original Show Desktop setting and both corner actions, then click Done.
