Start with common keyboard shortcuts

Use key combinations for common actions such as copy, paste, undo, switching apps, and searching, so you spend less time finding commands in menus.

Open this setting

Utilities & shortcuts

Before you start

  • The action for pressing the Fn/Globe key alone can be changed in System Settings > Keyboard, including switching input sources or showing emoji. To open emoji, use Control-Command-Space or Fn-E.

Settings path

Any app › Menu bar in the upper-left corner › Shortcut symbols beside menu commands

Steps

  1. Open an app such as Finder or Safari.
  2. Look at the menu bar in the upper-left corner of the screen. Open a menu such as File or Edit and notice that many commands show shortcut symbols on the right.
  3. Start with three combinations: hold the key labeled Command or ⌘, then press C to copy, V to paste, or Z to undo.
  4. When those feel familiar, try Command-Tab to switch apps and Command-Space to open Spotlight search.
  5. No system setting needs to be changed. Start using a shortcut whenever you repeat the related action.

Before

Each action requires moving to the mouse or trackpad and finding a command in the menu bar.

After

Common actions can be completed directly with key combinations, and many menu commands show their shortcut beside the name.

Undo the change

  • Nothing needs to be restored. To change or turn off system shortcuts, click the Apple menu in the upper-left corner, then choose System Settings > Keyboard > Keyboard Shortcuts.
