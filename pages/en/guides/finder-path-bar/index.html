Show the Finder path bar

Show the location and nested folders for the current file or folder near the bottom of a Finder window.

Open this setting

Finder

Settings path

Finder › View › Show Path Bar

Steps

  1. Open a Finder window.
  2. Look at the menu bar in the upper-left corner of the screen and confirm that “Finder” appears there.
  3. Choose View > Show Path Bar from the menu bar.
  4. Check the bottom of the Finder window and confirm that the current folder hierarchy appears.

Before

When the Path Bar is hidden, the bottom of the Finder window does not show the current location and its parent folders.

After

When the Path Bar is shown, the current location and its parent folders appear near the bottom of the Finder window.

Undo the change

  • In Finder, choose View > Hide Path Bar from the menu bar.
