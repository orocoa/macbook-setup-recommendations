Minimize windows into the application icon

Minimize an app window into its app icon instead of giving each minimized window a separate position in the Dock.

Open this setting

System Settings

Settings path

System Settings › Desktop & Dock › Minimize windows into application icon

Steps

  1. Open System Settings.
  2. Click Desktop & Dock in the sidebar.
  3. In the Dock section, turn on “Minimize windows into application icon.”
  4. Minimize several windows from the same app and confirm that they no longer appear as separate items in the Dock.

Before

When the option is off, minimized windows appear in a separate area of the Dock. Several open windows can create several minimized-window items.

After

When the option is on, minimized windows go into their application icon and no longer occupy separate positions in the Dock.

Undo the change

  • Return to Desktop & Dock and turn off “Minimize windows into application icon.”
